# BSP font subsets

English | [中文](README.zh.md)

The retained C fonts are subsets of OFL-licensed upstream fonts, not complete Chinese character sets. The application menu fonts are supplied by the separate Sugarat Game component.

Noto Sans SC and Source Han Sans retain SIL OFL 1.1. Keep font copyright headers and the accompanying OFL.txt. The root NOTICE records attribution. Derived primary font names must not use reserved upstream names.
