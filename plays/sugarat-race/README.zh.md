# Sugarat 圆屏竞速

[English](README.md) | 中文

## 概述

Sugarat 圆屏竞速提供体感赛车和滚珠竞速，各有三张固定地图。玩家倾斜设备转向，赛车自动加速；滚珠经过全部检查点后到达终点。菜单使用左右滑动和210×64像素大按钮。固件使用硬件资源包0.2.1中的SDGOODS ESP32-S3 360×360 BSP、ESP-IDF 5.5.4和LVGL 8.3.11。构建、主机检查和真机证据分别记录在[validation.json](validation.json)。

<a id="play"></a>
## 游玩

屏幕上的所有文字均为英文。在主页左右滑动选择Tilt Racer（体感赛车）或Marble Run（滚珠竞速），点击Play后继续左右滑动选地图。选择Solo，以舒服的姿势握住设备，平放、竖握或介于两者之间都可以，点击Start here；该姿势会成为两个倾斜轴的水平基准。比赛中长按屏幕空白处打开大按钮菜单。选图页长按返回主页，校准页或准备页长按返回选图。

赛车在三秒倒计时后开始，共三圈。左右倾斜转向，驶离道路会减速。单人模式中玩家从三辆电脑对手后方起步；对手会绕过较慢的车，并保持车队距离接近。每圈有四块橙色箭头加速带，压过后加速1.8秒；碰到对手会损失速度。不吃加速带的干净比赛通常获得第三或第四名。滚珠使用两个倾斜轴，按重力滚动，滚动阻力小，撞墙会反弹。收集三个金色检查点后到达方格终点。白球代表自己，连接后青色幽灵球代表对手。退出或断电不保存比赛和用时。

扬声器跟随控制中心音量。赛车播放随速度变化的引擎声、出界震动声、加速、碰撞、超车、圈数和完赛音效；滚珠播放随球速变化的滚动声、撞墙声和检查点提示音。两个游戏都有倒计时、发车和菜单点击音。音量为0时关闭功放。

附近对战时，两台徽章都需运行本版本并选择相同模式和地图，附近对战没有电脑对手。两台徽章点击Versus并校准，再分别点击Ready。两个匹配的附近准备页自动绑定并显示同一房间号。每个状态包重复发送准备、开局及确认字段，位置约以15Hz发送。每局限两台设备。先到终点的一方获胜：另一台立即结束比赛，显示Defeat - 2nd和获胜方用时并播放失败音效，获胜方显示Victory! 1st。失败方在数据包中标记认输，获胜方不会把这次停止误判为更快的完赛。双方都真正完赛时用时短者获胜，用时完全相同时主机获胜。

打开菜单、系统控制中心或失去新鲜体感读数时，本机暂停模拟，并向对手发送暂停状态；对手收到消息后暂停。连续1.5秒没有有效对端消息时，比赛冻结并报告连接中断。同一运行会话恢复通信后可以继续，设备重启后双方需要重新进入准备页。比赛结束后双方都选择Play again才能重赛。

ESP-NOW信道由CONFIG_RACE_RADIO_CHANNEL配置，默认6，可选1至11。附近对战要求相同信道，仅在准备页或比赛期间启动Wi-Fi。配对使用新随机标识并限定MAC地址，但不提供密码学身份认证或应用数据加密。无线失败时仍可返回单人模式。真正的双机无线行为、计时公平性和物理手势需要硬件验收。

<a id="build-and-check"></a>
## 构建与检查

激活ESP-IDF 5.5.4及ESP32-S3工具链，在仓库根目录运行：

```sh
idf.py -C plays/sugarat-race -B /tmp/sugarat-race-build build
python3 plays/sugarat-race/tests/check_host.py --output /tmp/sugarat-race-host
```

应用镜像为/tmp/sugarat-race-build/sugarat_race.bin。主机检查使用Clang、AddressSanitizer、UndefinedBehaviorSanitizer和Pillow，覆盖全部六张地图、三圈完赛、带加速带的对手比赛、驶离道路、平放与竖握校准、滚珠滚动、迷宫碰撞与完赛、迷宫缓存画面、音效峰值限制、丢包开局、通信过期和重放拒绝。每张C参考帧都必须与冻结预览逐像素一致。主机检查不能建立无线或真机行为结论。

<a id="maps-and-rendering"></a>
## 地图与绘制

原创地图、RGB565背景和像素图形由design/maps.json及main/race/generated.h定义。桌面参考图和固件使用同一套可移植C绘制代码。参考板分别为[赛车赛道](design/previews/racing-tracks-board.png)和[滚珠地图](design/previews/marble-maps-board.png)。本实现没有引入Tilt-a-tron或AmoledOS的游戏代码或美术。

一个工作任务拥有物理与会话状态。三块PSRAM帧缓冲通过短互斥交换所有权，未发布的绘制缓冲不会上屏。静态场景仅在页面、模式、地图或阶段变化时绘制。迷宫静态层缓存在PSRAM中，填充矩形和圆形每行只裁剪一次圆屏边界。IMU任务优先级高于显示任务，倾斜读数保持100Hz。菜单、倒计时和系统浮层使用LVGL，无遮挡的比赛画面可使用随附的条带直推组件。直推不可用时回退LVGL。传感器数据过期时冻结比赛并显示恢复提示。

Game组件拥有菜单控件和字体。地图名和迷宫提示是由design/generate_reference.py生成的英文标签。串口诊断键a/b分别点击下方/上方大按钮，[/ ]分别左右滑动，m长按中央。这些路径经过真实BSP输入驱动；BSP的s命令截取当前LVGL画面。合成输入和截图不能验证物理手指、IMU运动或面板外观。

<a id="device-installation"></a>
## 设备安装

遵循[硬件部署流程](../../../hardware-kits/sugarat-sdgoods/references/deployment.md)，写入前检查当前芯片、Flash、分区表和启动应用。构建成功不代表可以替换启动器。只把应用BIN写入本次检测确定的地址，保留NVS和appdata；跳过备份需要用户明确指示。

应用保留BSP外壳、控制中心、电源行为和受管理应用的退出钩子，不修改分区表，也不选择OTA槽。单应用写入不能建立启动器安装兼容性结论。实际写入、字节校验、启动和未验证项目以validation.json为准。
