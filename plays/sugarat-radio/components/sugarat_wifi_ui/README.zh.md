# 谷仓 Wi-Fi 配网界面

[English](README.md) | 中文

安装时选择 `sdgoods-wifi-ui`、`target=esp-idf`，目录使用谷仓固件工程根目录，其依赖会安装网络组件。在 `main/REQUIRES` 中添加 `sugarat_wifi_ui`，先初始化 BSP/LVGL 和网络管理实例，再于 LVGL 线程调用 `sugarat_wifi_ui_create(wifi)` 与 `lv_scr_load(screen)`，并检查错误码和返回指针。销毁网络前先删除屏幕，屏幕删除会移除界面定时器并释放状态。

## 成功回调与应用页面

调用 `sugarat_wifi_ui_default_config()`，设置 `on_connected` 和 `user_data`，再调用 `sugarat_wifi_ui_create_with_config(wifi, &config)`。回调参数为 `(setup_screen, const sugarat_wifi_event_t *, user_data)`，在获得 DHCP 地址、提交凭据及关闭热点和服务后于 LVGL 线程执行。回调可以创建并加载应用页，再同步删除 `setup_screen`；返回后组件不会继续访问已删除的界面状态。保留事件内容前须复制，用户数据的生命周期须覆盖界面。

已成功建立的连接会在第一次定时器回调时回放一次，因此界面创建期间的启动重连不会漏掉跳转；创建函数本身不会调用处理器。后续每个连接序号仅自动跳转一次，重复轮询不重复跳转。重新进入设置时应设置 `notify_current_connection=false`，让设置页保持打开。已配置 `on_connected` 且当前连接有效并已保存时，配网首页左上角显示返回应用箭头。点击后会用保留的连接事件再次调用同一导航回调，即使该序号已投递过；应用不得按连接序号去重而丢弃这次主动返回请求。配网热点仍开启时，组件先请求关闭并等待确认，再返回应用。保存失败、连接断开或热点关闭失败时不返回；关闭请求忙或失败时保留可重试提示。网络、密码和热点子页面的返回箭头先回到配网首页。删除界面会取消后续通知。原有 `sugarat_wifi_ui_create` 继续可用，但不提供应用跳转回调。

需要可运行的占位应用时，将 `examples/setup_flow.c` 加入调用方应用的源文件列表，将 `examples/` 加入头文件搜索路径，包含 `setup_flow.h`，再加载 `sugarat_wifi_example_create(wifi)`。示例会从配网页切换至带矢量状态图形的 App ready 首页，点击 Wi-Fi settings 可重新进入设置，且不回放已有成功连接。示例不提供凭据、BSP 初始化、分区修改或应用入口。将其 `connected` 回调替换为项目业务页面即可，联网和输入代码继续复用。加载前须检查返回的界面指针。

默认英文界面采用浅色分组布局和蓝色主操作，提供两种方式：在设备上选择扫描到的网络，通过分组触摸键盘输入密码；或用手机免密码连接屏幕显示的开放热点，打开本地网页。语言按钮可切换中文，两种方式共用网络状态和扫描代数，不创建可编辑的 SSID 输入框。繁忙、扫描、连接、成功、失败及保存失败均有可见反馈。成功配置在重启后自动连接，点击“连接成功”可打开连接详情和明确的清除网络操作。

配网控件均位于 360x360 圆屏中 (60,60) 起始的 240x240 安全区域。主页使用两个 68px 高的配网卡片，分别配有 Wi-Fi 扫描和手机热点图标，网络列表每页显示两个 54px 高的选项，并提供前后翻页和扫描控件。所有触控区域至少为 48x48px。密码键盘每页显示六个大按键：先选择小写、大写、数字或符号，再用向右箭头图标切换字符，用键盘图标切换分组。矢量眼睛、退格和空格图标分别控制密码显隐、删除及输入空格，连接操作保留文字标签。图标图形不会拦截按钮点击，按钮文字及卡片标题与说明均垂直居中，热点指引和连接详情在圆屏上水平居中。请在进入密码页前选择界面语言。密码默认隐藏，可主动显示。随组件提供 16px 和 20px 的 Noto Sans SC Medium 子集字体及 SIL OFL 许可，覆盖组件全部界面文案、ASCII 和一部分中文，不覆盖任意 Unicode 网络名，遇到生僻网络名需扩展字形。要求 LVGL 8.3.11。

组件不会安装 BSP 引脚、分区表、应用入口、原生预览适配程序或设备观测。桌面预览需要独立的无线功能实现，不能直接链接 ESP-IDF 无线代码。必须在设备上验证触摸、键盘、语言显示、列表滚动及两种配网方式，编译成功不能代替这些验证。
