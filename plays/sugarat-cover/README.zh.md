# Sugarat Cover

[English](README.md) | 中文

## 摘要

Sugarat Cover 在 SDGOODS ESP32-S3 的 360×360 圆屏徽章上全屏展示图片。手机通过徽章的本地 Wi-Fi 页面管理图片，附近徽章通过 ESP-NOW 交换图片副本。设备与手机界面默认英文，共用已保存的中英文偏好。编译和主机模拟不能确认真机触摸或无线表现。

<a id="controls"></a>
## 设备操作

轻点封面显示“手机上传”“交换图片”和语言切换。左右滑动切换当前封面，前后两张图片会预先解码，滑动时不会因解码停顿，菜单在七秒后关闭。主按钮为 228×60 像素，双按钮各为 108×60，间隔 12 像素，语言控件为 60×60。功能页通过至少 60 像素的从左向右滑动返回，也接受从按钮上起手的滑动。手机上传返回操作菜单，附近设备、配对和传输页面返回交换菜单。退出无线页面会停止对应连接，关闭完成前不接受新操作。界面不设置返回按钮。控件均位于 (60,60) 起的 240×240 安全矩形内。只有松手仍在原按钮范围内、两个方向移动均不超过 24 像素时才触发；拖出后再拖回不会触发。图库变化、控件重建或浮层会取消按住的操作，必须松手，新控件才接受下一次输入。语言更新保留现有控件，保存完成不会取消其他按钮上正在进行的按压。封面滑动至少需要 40 像素横向距离，主要沿竖直方向的移动不会切图。

<a id="phone-management"></a>
## 手机管理

选择“手机上传”，徽章先显示 Sugarat 热点名称，提示到手机 Wi-Fi 设置中连接；此步骤没有二维码，默认无需密码。“开启密码”会启用新的八位数字 WPA2 密码，并在徽章上直接显示；“取消密码”恢复免密码热点。切换该选项会重启热点。手机提示没有互联网时仍需保持连接。只有手机连接后，徽章才显示管理页面二维码，内容为 HTTP 地址，不是 Wi-Fi 连接信息。使用手机相机扫码，或在浏览器输入 `http://192.168.4.1`。

热点 DNS、HTTP 探测重定向和 DHCP 选项 114 为支持的手机提供自动页面入口；是否弹出窗口由手机系统决定。安卓连接 Wi-Fi 后弹出的登录窗口无法打开相册；在该窗口点击上传而没有打开相册时，页面会提示改用浏览器打开 `http://192.168.4.1` 或扫描页面二维码。根地址会转入当前本地管理会话，因此无需手动复制令牌。图片 API 和修改操作仍要求会话令牌。本版本不提供云服务。

选择图片，拖动裁剪位置、调整缩放或旋转，然后上传。浏览器导出 360×360 JPEG，并提供圆屏预览。上传只保存副本，不会替换当前封面；选择已保存的图片并点击“设为封面”后才展示。“管理”允许删除其他图片，当前封面需要先切换才能删除。页面语言切换会保存共用偏好，刷新页面后仍保留。

<a id="nearby-sharing"></a>
## 附近赠图

一台徽章选择“交换图片 → 接收图片”；另一台选择“赠送这张”，再按标识后缀选择附近徽章。核对两块屏幕上的六位配对码，并在双方确认。图片通过 ESP-NOW 传输，使用临时 P-256 密钥协商与 AES-GCM 应用层加密。接收方保存完成后，发送方才报告送达；最终确认丢失会报告结果未知，并提示检查对方相册。双方原图均保留，收到的图片只有在选择“展示”后才成为封面。

手机管理与附近赠图分时运行。双方必须使用相同的 2.4 GHz 信道；`CONFIG_COVER_CHANNEL` 接受 1–11，默认为 6。[共用协议](main/cover/cv_link.c) 实现发现、确认、数据包应答、重复处理和有次数限制的重试。主机传输模拟覆盖该协议，但不测量无线吞吐量或距离。

<a id="storage-and-failures"></a>
## 存储与故障

语言切换在后台保存，完成前语言控件显示省略号，其他控件仍可使用。保存失败会显示可操作的错误，不会声称语言已保存。

相册最多接收 32 张 JPEG，每张不超过 160 KiB；实际文件系统空间可能进一步限制容量。图片位于应用的 `sugarat_cover` appdata 目录，NVS 保存当前图片、语言和初始图片标记。内容标识用于去重相同图片，暂存文件同步并重命名后才会出现在相册中。保存或语言设置失败会明确报错，不会声称成功。

[基础工程](SUGARAT_TEMPLATE.md) 保留平台分区表，不会擦除 NVS。appdata 分区整体为已擦除状态时，首次挂载会创建文件系统；损坏或外来的文件系统永远不会被格式化。存储异常会禁用相册写入并显示错误；应用不提供损坏存储的恢复流程。Flash 写入与触摸读取串行，写入结束后只保留 40 ms 稳定等待。这消除了保存后继续占用预留数秒时间的输入延迟；实际触摸响应仍需真机验收。

<a id="build-and-verification"></a>
## 构建与验证

使用 ESP-IDF 5.5.4 及其 Python、工具链环境。[tools/build.py](tools/build.py) 必须通过 `--sdk` 指定 SDK，可通过 `--tools` 指定工具链根目录、`--output` 指定构建目录；它只执行编译，不打开串口。默认输出为仓库中的 `/tmp/sugarat-cover-build/sugarat_cover.bin`。本地 LVGL 组件无需从组件仓库下载。

[tools/check_host.py](tools/check_host.py) 需要 CMake、Ninja、OpenSSL 3 和 Pillow。传入匹配的 `--sdk` 可同时构建真实 HTTP 处理器适配器，以及启用内存和未定义行为检查的存储、协议与 LVGL 测试。它核对应用内的[双语界面快照](tests/expected/ui-text.txt)，并渲染设备截图。[tests/web_check.mjs](tests/web_check.mjs) 使用仓库 Playwright 和该适配器，检查浏览器裁剪、上传、展示、删除、语言持久化、访问失败与窄屏布局。这些检查使用主机存储和网络适配器，不执行 ESP32 外设。

显式启用 CMake 选项 `COVER_UI_DIAGNOSTICS` 可加入设备测试组件，执行可重复的指针输入测量。M/L/U/B 命令分别打开菜单、切换语言、打开上传和右滑返回；完成判据是目标界面出现且重绘完成。正常构建不包含这些命令。

构建证据和截图位于 `/tmp/sugarat-cover-`。这些检查不写入设备。后续单独授权部署时，先比较实际目标设备和分区布局、保留已有数据，再分别验证写入字节、启动、显示、触摸和双设备传输。

## 来源与限制

[NOTICE](NOTICE) 保留 SDGOODS、LVGL、Watch 字体图标和应用来源说明。初始落日图片来自仓库的 UI 主题实验室。应用使用已核对的[硬件标识](hardware-product.json)，不增加通用产品默认值。手机上传接收浏览器可解码的图片并导出静态 JPEG；动画、云管理、路由器模式、自动双向互换和轮播不在本版本范围内。真实断电恢复、实体按钮与触摸、二维码扫描、无线互通、吞吐量和续航仍需设备验收。
