# Sugarat 社交名片

[English](README.md) | 中文

## 摘要

在 360×360 谷仓 SDGOODS ESP32-S3 徽章上展示公司、昵称、身份、一种联系方式和个人链接。上滑打开名片码、设备交换、手机编辑、已收名片和语言设置。[验证记录](validation.json)分别报告本机检查、固件编译与实物验收。

<a id="controls"></a>
## 操作

首页以 28px 展示姓名，将身份和公司合为一行 16px 文字，联系方式和主页各自居中。长字段横向滚动。从屏幕下部向上滑出面板；面板跟随手指并吸附到位。四个图标按钮为 96×64 像素，水平间隔 24 像素、垂直间隔 8 像素，下方另有 104×40 像素的语言控件；五个触控区域均位于圆屏内。下滑或点击外部空白收起，滑过图标不会执行操作。子页从左边缘向右滑返回，不显示返回按钮。已收名片从页面内部左右滑动切换，到端点后停止。BSP 保留顶部下拉控制中心、暂停与恢复、返回启动器和电源锁存行为。

没有偏好记录时，设备默认英文；已有语言偏好继续生效。抽屉语言控件在独立 NVS 设置提交和回读成功后切换中英文，不改变名片存档格式；保存无法确认时显示错误并保留当前界面语言。

<a id="phone-editing"></a>
## 手机编辑

从面板打开编辑。与[封面玩法](../sugarat-cover/README.zh.md#phone-management)一致，先在手机 Wi-Fi 设置中连接屏幕显示的 Sugarat 热点。这一步不显示二维码，默认无需密码。「使用密码」会重启热点并生成新的八位数字 WPA2 密码；「移除密码」恢复免密热点。手机提示无互联网时保持连接。手机连上后，设备自动显示编辑页面二维码；断开连接则返回连接提示。

Captive DNS、HTTP 联网探测重定向及 DHCP 选项 114 为支持的手机提供自动页面入口，是否弹窗由手机系统决定。未弹出时，用手机相机扫描页面码，或在浏览器输入 `http://192.168.4.1`。根地址会跳转到当前编辑会话，资料接口仍需该会话的授权。填写资料并保存，只有设备完成提交和回读验证后，网页才报告成功。不需要账号、云服务或手机应用。左缘返回、打开系统控制中心、关机及默认五分钟超时会关闭热点。重新进入会生成新的授权；热点编辑和 ESP-NOW 分时运行。

文字上限按 UTF-8 字节计算：昵称 48、公司 64、身份 64、联系方式 96、网址 160。昵称必填。联系方式可选邮箱、电话或微信号；网址使用 HTTP 或 HTTPS。设备校验文字并拒绝不支持的字符。设备中的长字段横向滚动，手机预览以省略号显示；名片码和交换保留完整内容。手机预览用于核对内容，不代表经过校准的设备模拟。所有字段均属于公开名片资料。编辑页初始使用设备语言，可独立切换，URL 会保留选择以供刷新；切换语言保留输入内容，并翻译校验、授权和保存错误。

<a id="device-exchange"></a>
## 设备交换

两台徽章都打开交换页面，发现并主动选择对方。设备显示相同的六位数字，用户在两块屏幕上核对后分别确认。临时 P-256 密钥协商生成分方向的 AES-GCM 密钥。只有双方的认证确认均到达后才传输资料。分片在有限窗口内重试，拒绝重放并防止重复收取；只有本机保存和回读验证成功后才确认收妥。成功需要本机收到名片且对方确认收妥；本机已保存但等待超时的情况会明确显示对方结果未确认。发现广播包含昵称和临时配对数据，联系方式在加密传输中发送。本协议用于同款应用之间互通。

<a id="saving"></a>
## 保存

应用使用独立的 `sugarat_card` 身份和数据目录，已有私有 NVS 记录保持优先。其余情况使用已挂载 appdata 中带序号和 SHA-256 校验的两份文件；缺少 appdata 分区时允许回退到私有 NVS。文件系统损坏或不可用、存档无效、版本未知或写入无法确认时停止修改并保留记录供恢复；不擦除或格式化文件系统及共享 NVS 分区。NVS 写入保留空闲条目余量，共享空间不足时可能拒绝保存。存储中的字段为明文。名片夹可收十二位联系人，同一身份再次交换会更新对应记录，新身份在容量用完后被拒绝，不自动淘汰联系人。

<a id="build-and-checks"></a>
## 构建与检查

激活面向 ESP32-S3 的 ESP-IDF 5.5.4，然后从仓库根目录运行：

```sh
idf.py -C plays/sugarat-card -B /tmp/sugarat-card-build build
```

单一应用镜像为 `/tmp/sugarat-card-build/sugarat_card.bin`，版本 0.1.2。平台分区表保留初始化模板原文。后续安装前需要重新检查实际设备布局与启动器可用容量；编译不会授权或执行写入。

将 `IDF_PATH` 指向 SDK 源码目录，并准备 CMake、Ninja、OpenSSL 3、Python 和 Pillow 后运行：

```sh
python3 plays/sugarat-card/tools/check_host.py --output /tmp/sugarat-card-checks
```

每次运行使用新的输出目录，包含本机构建、内存检查结果、双语文字快照、实际 LVGL 图片和 `drawer-swipe.gif`。浏览器编辑检查另需仓库已有的 Playwright 和 Chromium；将该次运行的 `build` 目录传给 `tools/check_editor.py --build <build-directory> --output <review-directory>`。检查使用私有回环服务器及真实 C 解析和文件存储，覆盖双语、刷新、窄屏和保存未确认。本机检查还通过 NVS 适配器和写入失败注入，验证真实语言持久化实现。本机 HTTP 检查执行固件处理函数，覆盖根地址与联网探测跳转、Captive JSON、接口授权及排队和保存失败响应。两类检查均不模拟 ESP-IDF Wi-Fi 驱动。

`tools/prepare_assets.py --check` 校验嵌入的编辑页。不带该参数运行会重新生成页面；另传 `--font-dir <lvgl>/scripts/built_in_font` 会从保留的思源黑体输入重新生成字体。源码已包含字体，普通固件编译不需要字体生成器。

<a id="limits-and-sources"></a>
## 限制与来源

应用使用 Sugarat SDGOODS 资源包 0.2.1 及其 BSP、LVGL 8.3.11 和 Watch 控件。应用生成的 16 和 28 像素字体以两位字形位图包含基本中日韩统一表意文字区，不支持表情符号。较大字库会增加应用镜像体积，启动器安装时必须核对实际可用容量。BSP、应用、LVGL、字体和图标设计保留随附许可与声明。Fri3d Friends 提供交互方向参考，本应用未引入该项目或 GPL 徽章项目的代码。[硬件参考](../../../hardware-kits/sugarat-sdgoods/references/hardware.md)标识文档对应的板卡。

本固件不提供 NFC、头像上传、兴趣匹配、vCard 文件导入、联系人删除或云同步。耗电、实物帧率、手机连接热点、扫码、双机无线距离和启动器共存需要真机验收。[应用入口](main/apps/ui_helloapp.c)负责运行时接入；[界面](main/card/card_view.c)、[交换](main/card/card_exchange.c)、[网络](main/card/card_network.c)和[存储](main/card/card_store.c)分别拥有对应行为。随附检查不访问串口或写入设备。
