# 角色与陪伴案例

[English](README.md) | 中文

在谷仓 360 像素圆屏徽章上复用用户已验收的互动宠物、八表情徽章或语音状态场景。通过 本资源包入口说明中的独立安装脚本 安装 `sdgoods-case-companion`，指定 `target=esp-idf` 和项目语言。依赖包含 Watch 控件和 20 个 Pixel 角色。在主应用的 `REQUIRES` 中加入 `sugarat_companion`；安装保留已有应用入口和定制文件，不访问设备。

## 场景与语言

选择 `SC_SCENE_PET`、`SC_SCENE_MOODS` 或 `SC_SCENE_VOICE`。优先按用户明确要求的语言选择 `SC_LOCALE_ZH` 或 `SC_LOCALE_EN`，其次遵循参考内容语言，再次遵循会话语言。两个文案文件包含全部标签、状态和角色名字。保留已验收的表现：角色周围没有圆圈，以当前 IP 名字为标题，提供单独的语言按钮，独立案例设置 `gallery_navigation=false`。只有明确要求测试总览时才开启总览导航。

宠物支持触摸与玩耍反应、睡觉/叫醒和本地互动计数。表情徽章支持八种表情和动效切换。点击 IP 名字选择下一个角色。语音演示在按住时显示聆听，松手后显示思考、回答和待机，且标明不录音。演示离线会取消流程，并保持离线直到明确切换。所有状态仅保存在内存中，重启后重置。

## 集成与资源归属

阅读 `include/sugarat_companion.h`，随后在 LVGL 线程使用显式 `sc_config_t` 调用 `sc_open()`：单调时钟 `now_ms`、场景、语言、角色、正数反应/思考/回答持续时间、语音模式和总览选择。加载返回页面，将 `sc_set_paused()` 绑定到产品外壳的暂停/恢复回调，加载其他页面后再删除它。页面拥有并释放自身定时器和角色动画。`companion_model.h` 提供不依赖 LVGL 的本地互动计时。

有明确标注的本地演示使用 `SC_VOICE_DEMO`。真实语音使用 `SC_VOICE_EXTERNAL`，并提供 `on_voice` 和调用方拥有的 `user_data`。外部模式从离线开始，不运行模拟切换。LVGL 线程上的同步回调在接受按压时收到 true，松手或取消时恰好收到一次 false，包括隐藏屏幕和删除页面。按住期间服务状态变化不会丢失停止请求。不要在回调中删除页面。页面存活期间，在 LVGL 线程通过 `sc_set_voice_state()` 上报真实服务状态。服务负责音频、网络、认证、重试和关闭；释放服务资源前必须等待其关闭完成。此组件不会启动任何服务。

## 验证

无圆圈、IP 名字标题的布局在通过 Flash 写入、独立摘要校验和启动检查后，已由用户在谷仓圆屏徽章上验收，环境为 ESP-IDF 5.5.4 和 LVGL 8.3.11。原生测试覆盖中英文、全部 20 个角色与八种表情、32 KiB LVGL 内存池、圆屏点击区域、持续按压、中断和完整释放。仓库的 `examples/companion` 测试工程直接构建此组件。每个新集成仍需独立构建和实物验证；语音演示不能证明音频或云服务已正常工作。
