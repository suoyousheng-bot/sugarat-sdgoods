# 数据与仪表案例

[English](README.md) | 中文

复用谷仓 360 像素圆屏徽章上的温度仪表、温湿度及电量看板、有限历史曲线或上限告警。通过 本资源包入口说明中的独立安装脚本 安装 `sdgoods-case-data`，选择 `target=esp-idf` 和项目语言；依赖中包含 Watch 控件及其字体。在 main 的 `REQUIRES` 中加入 `sugarat_data`。安装会保留定制文件和应用入口，不访问或烧录设备。

## 场景与语言

选择 `SD_SCENE_GAUGE`、`SD_SCENE_OVERVIEW`、`SD_SCENE_HISTORY` 或 `SD_SCENE_ALARM`。先遵循用户明确指定的语言，再按参考内容语言，最后按会话语言选择 `SD_LOCALE_ZH` 或 `SD_LOCALE_EN`。语言按钮切换资源时不重置数据或告警确认。独立案例使用 `gallery_navigation=false`，只有明确要求的测试总览才启用箭头。仅仪表页使用全屏量程环。

历史仅在内存保存最近 48 条采样或缺失记录，按采样槽等距排列，不表示时间轴。无效、离线和过期间隔会断线。温度达到配置上限时触发告警，降至上限减去正迟滞值时解除。确认后仍保留告警，直到收到有效恢复读数；恢复后再次告警需要重新确认。重启会清空历史和确认状态。

## 数据接入与归属

阅读 [sugarat_data.h](include/sugarat_data.h) 和 [data_model.h](include/data_model.h)。在 LVGL 线程调用 `sd_open()`，明确指定单调时钟、场景、语言、来源标识、量程、过期时间、正刷新间隔和导航选择。配置无效会返回 NULL，不创建页面。使用 `lv_scr_load()` 加载返回的页面，将 `sd_set_paused()` 绑定到产品外壳的暂停恢复；删除页面会释放定时器和状态，删除前须加载其他页面。

真实遥测使用 `SD_SOURCE_EXTERNAL`。数据源负责解析输入，将完整读数转交 LVGL 线程，并在页面存活期间调用 `sd_publish()`。温度使用有符号的 0.1 摄氏度整数单位，湿度与电量使用 0 至 100 的整数百分比。被拒绝的读数会隐藏全部当前数值，保留上次有效采样与告警，并增加历史缺失记录。`sd_disconnect()` 表示数据源丢失。数据时效采用单调接收时间；过期、离线和无效数据不会变成零读数，也不会解除有效告警。

组件从无数据开始，不采集传感器、不连接服务，也不生成采样。`SD_SOURCE_DEMO` 仅增加持续显示的演示标识；演示数据必须由调用方明确提供。删除页面前停止数据源回调。隐藏期间可接收数据但暂不渲染，恢复时重新评估时效。保留 BSP 管理权和现有应用入口。

## 验证

用户已确认实际 LVGL 静态预览，并明确跳过烧录和实物验收。ESP-IDF 5.5.4 固件编译已通过。上游 Sugarat 回归测试工程构建相同源码，检查中英文、32 KiB LVGL 堆、圆屏边界、文字重叠、字形、导航、暂停恢复、释放和已记录的界面文本。模型测试覆盖输入校验、到期时刻、有限历史、缺失断线、迟滞、确认和重新触发。实物显示、触摸、电源和真实传感器行为仍未验证；每个新硬件集成都需要自行验证。
